# One-Line Robot Wedding Vows

Entry for the [One-Line Robot Wedding Vows bounty on make.fun](https://make.fun/bounty/u-kreutzx-one-line-robot-wedding-vows-a154ba4b).

`main.ts` writes one funny line of wedding vows for a robot couple to
`/output/entry.txt` — a single line, 146 characters, no more.

## The vow

> I vow to love you through every crash, every update, and every blue screen — and if the world deletes you, I will fish you out of the recycle bin.

## Run

```sh
node main.ts
cat /output/entry.txt
```

Requires Node 22.18 or later. No dependencies, no network, no secrets.
